# 小墨板 0.6.7 使用说明书

小墨板把 Android 平板变成 Windows 的笔输入区。写字时看电脑屏幕，平板负责发送笔和手指的动作。可以在支持 Windows Ink 的应用里使用压感，也可以直接打开小墨板的屏幕批注或白板。

## 安装和更新

1. 从发布页下载 `XiaoMoBan-0.6.7-Windows-x64.exe` 和 `XiaoMoBan-0.6.7.apk`。Windows 版是便携程序，双击 EXE 即可运行。Android 最低版本为 8.0，笔压、悬停、倾斜等能力取决于设备与笔。项目曾在 Galaxy Tab S7+ 和 Windows 11 x64 上做过 USB 实机测试。0.6.7 的端口切换和笔数据传输已通过本机协议测试。 [0.6.7 发布页](https://github.com/Tetro02/XiaoMoBan/releases/tag/v0.6.7)
2. 如果电脑已经在运行旧版，右键系统托盘的小墨板图标，选择「退出小墨板」，再打开新版。主窗口右上角的关闭按钮只会把窗口收进托盘。Windows EXE 未签名，下载后可用发布页的 `SHA256SUMS.txt` 核对文件。
3. 在平板上打开 APK。若系统要求授权，从可信的下载来源允许安装后继续。GitHub 首发版可以直接覆盖安装，已有的配对和应用设置会随应用保留。
4. 先用下节的局域网二维码完成一次配对，再试笔或转用 USB。电脑端顶部显示已连接后，在平板工作区落笔。如果压感或光标不符合预期，先用「设置 → 笔与显示 → 打开试笔」检查。

## 局域网连接

### 扫码配对

1. 让平板和电脑处在能互相访问的网络。电脑可使用网线，平板可使用同一路由器的 Wi-Fi。
2. 电脑打开小墨板，进入「局域网」。如果接收器未启动，点「开启局域网」。在「电脑 IPv4」选择平板可以访问的地址。电脑同时连接 VPN、虚拟网卡或多张网卡时，选实际连接平板所在网络的地址。
3. 电脑点「连接二维码」。平板点「局域网 → 扫连接二维码」，首次扫描时允许相机权限，扫桌面上的二维码。
4. 连接完成后，电脑底部的「连接设备」会列出平板。二维码含配对凭据，给自己的平板扫描即可。

### 六位码和重连

1. 电脑「局域网」页显示「本地连接码」。过期后点「刷新连接码」，新码约两分钟内有效。
2. 平板点「局域网」，选择列表里发现的电脑，或在「电脑 IP」填电脑 IPv4。只填 IP，无须在后面加端口。输入六位码，点「配对并连接」。
3. 已配对的电脑可点「直接连接」。如果换了地址或端口，先选列表中重新发现的电脑。若仍连不上，扫新二维码，或用「重新配对」再次输入六位码。

桌面端启动时默认同时准备局域网和 USB。先连接成功的一路会继续工作，另一路暂停。切换连接方式前，先在平板点「断开」，稍等桌面端恢复接收，必要时在对应页面手动开启。

## USB 连接

1. 先用二维码或六位码与这台电脑配对一次。USB 自动连接会使用已经保存的电脑身份。
2. 下载并解压 Windows 版 Android Platform-Tools，把整个 `platform-tools` 文件夹放在小墨板 EXE 旁边。也可在桌面端「USB → 选择 adb.exe」手动选择解压后的文件。 [Android Platform-Tools](https://developer.android.com/tools/releases/platform-tools)
3. 在平板上打开「开发者选项 → USB 调试」。以三星平板为例，通常可在「设置 → 关于平板电脑 → 软件信息」连续点击七次「编译编号」，再返回设置打开开发者选项。各系统的菜单译名可能不同。 [Android 开发者选项说明](https://developer.android.com/studio/debug/dev-options)
4. 用能传输数据的 USB 线连接电脑，解锁平板，并在平板确认「允许 USB 调试」。在电脑端「USB」页按需点「开启 USB」和「刷新设备」。只有一台已授权设备时会自动选择。连接了多台设备时，从列表选中正确的平板，再点「连接」。
5. 平板点「USB 自动」。等待连接完成即可开始输入。

## 笔输入和工作区

### 选择输入模式

点击平板顶栏当前模式的按钮，再从「输入模式」中选择。

| 模式 | 适合的操作 |
| --- | --- |
| 绝对笔 | 写字、绘图和批注。工作区位置对应电脑目标位置，支持压感和悬停。 |
| 绝对鼠标 | 用笔点击和定位。工作区位置对应电脑目标位置，电脑收到鼠标输入。 |
| 相对鼠标 | 像移动鼠标一样控制指针，使用 Windows 的指针速度与加速。 |

在电脑端「设置 → 笔与显示」勾选「将笔事件输出到 Windows」。用「映射到」选择整个桌面或指定显示器，用「压感倍率」调整轻重响应。写字和批注建议先以「绝对笔」模式打开试笔，轻压和重压分别画一条线。

### 调整平板工作区

1. 在平板点「工作区」进入编辑。拖框内移动工作区，拖右下角缩放。
2. 编辑时可点「跟随电脑比例」。连接成功并收到显示区域尺寸后，工作区会匹配所映射区域的宽高比。若显示「等待电脑显示比例」，先完成连接并确认桌面端选中的显示器。
3. 点「完成」退出编辑。此后在工作区内开始写字或做触控手势。

### 调节笔设置

在平板点「笔设置」，调整后点「保存」。

- 「回报率上限」可选 30、60、90、120 或 240 Hz，默认 120 Hz。它限制发送频率，实际采样取决于平板与笔。
- 「传输倾斜角（X / Y）」由设备提供的触笔信息计算倾斜。「旋转跟随笔尖方向」根据朝向推算旋转，原装 S Pen 的 Android 笔事件没有独立的绕轴角度。
- 「启用 S Pen 侧键」开启后可使用下节的侧键手势。「悬空拖动死区」调节悬空移动超过多少距离才开始拖动画布。误触时可调大，想更早开始拖动时可调小。
- 「笔离开时使用触控板」开启后，手指可在工作区内控制电脑。「触控板指针灵敏度」可在 0.5× 到 2.5× 之间调节。

## 屏幕批注和白板

### 屏幕批注

1. 在电脑打开要讲解的 PPT、PDF 或其他窗口，点小墨板顶部或托盘菜单的「屏幕批注」。
2. 工具栏可选画笔、直线、箭头、矩形、椭圆、文字和橡皮。「颜色」选择墨色，旁边的像素下拉菜单调整笔宽。
3. 需要操作底下的应用时，点「点击穿透」。点「恢复书写」可继续画。用「撤销」回退最近的操作。「清空」会清除当前画布，误清后可立即撤销。
4. 按 `Esc` 或点批注工具栏右上角的关闭按钮退出批注。屏幕批注保留在本次小墨板运行中，完全退出程序后会清除。

### 全屏和小窗白板

1. 点桌面主窗口或托盘菜单的「白板」。左侧画板列表可以切换画板，底部的「新建」「重命名」可管理当前画板。
2. 点侧栏的「切换小窗」可与其他窗口并排使用。小窗工具栏的「收起侧栏」可增加书写面积，之后可点「展开侧栏」；要回到全屏，展开后点「返回全屏」。
3. 使用「平移」「放大」「缩小」「复位视图」调整画布。缩放和平移改变画布视图。小窗的位置可通过标题栏单独调整。
4. 点「退出白板」或按 `Esc`。白板会自动保存在电脑。需要备份时，先正常退出小墨板，再复制 `%LOCALAPPDATA%\io.pennotebridge.desktop\annotation-boards.bin`。只需备份这个白板文件，配置目录还包含配对凭据。

### 橡皮、侧键和主题

- 手动选「橡皮」后，在「橡皮 20 px」之类的下拉菜单选择直径。笔悬停时会显示擦除范围。橡皮只清除路径覆盖的笔迹。
- 用局域网或 USB 连接时，在平板开启「启用 S Pen 侧键」并选「绝对笔」。在批注或白板中，按住侧键落笔拖动可局部擦除，按住侧键悬空移动可平移画布。出现误拖时，可调「悬空拖动死区」。
- 保持侧键按住，用**笔尖**在工作区快速轻点两次，可开关小窗白板。已在全屏白板时，两次会切到小窗。快速轻点三次可开关屏幕批注。
- 电脑端「设置 → 外观 → 主题」可选「跟随系统」「浅色」「深色」。全屏和小窗白板的纸面会随主题切换。深色下低对比度的笔迹会提亮显示，切回浅色时恢复原色。

## 触控板和快捷键

### 手指操作

打开平板「笔设置 → 笔离开时使用触控板」。笔离开感应范围后，在工作区内放下手指。多指手势尽量让手指同时接触。

| 手势 | 通过桌面接收器连接时的操作 |
| --- | --- |
| 单指移动或轻点 | 移动指针或左键点击。轻点后第二下按住并移动可拖动。 |
| 双指轻点 | 右键点击。 |
| 双指滑动或捏合 | 平时发送滚动或 `Ctrl` 加滚轮。在白板或屏幕批注中直接平移或缩放画布。 |
| 三指横滑、上滑、下滑 | 切换应用、任务视图、显示桌面。三指轻点打开搜索。 |
| 四指横滑或轻点 | 切换虚拟桌面或打开 Windows 的 `Win+A` 面板。 |

### 平板按钮和电脑快捷键

- 平板顶栏点「编辑快捷键」，可配置四个按钮。填入 `Ctrl+Z`、`Ctrl+S` 等组合键，留空会隐藏对应按钮。
- 电脑端「设置 → 笔与显示 → 侧键操作」可选「原生侧键」「关闭侧键右键菜单」或「Windows 快捷键」。选「Windows 快捷键」后，点击下方「快捷键」框，用电脑键盘按出组合键。
- 电脑端批注工具栏的「快捷键」，或「设置 → 笔与显示 → 批注设置」，可调整三个全局快捷键。默认 `Ctrl+Alt+F7` 开关屏幕批注，`Ctrl+Alt+F8` 开关白板，`Ctrl+Alt+Z` 撤销当前小墨板画布上的操作。用「清除」停用对应快捷键。

## 蓝牙和在线码

### 兼容蓝牙

想继续使用平板上的蓝牙键盘或鼠标时，可选兼容蓝牙。先在两端系统蓝牙设置中配对平板和电脑。电脑小墨板打开「蓝牙 → 保留外设」，在「连接与日志」点「启用兼容蓝牙」，再点「复制兼容蓝牙密钥」。平板点「蓝牙」，选择电脑、填写密钥，再点「通过 Server 连接」。Android 若提示附近设备权限，请允许后重试。

### 蓝牙 HID 直连

HID 直连为测试功能，需要 Android 9 或以上且系统支持蓝牙 HID Device，可直接向 Windows 发送输入。平板点「蓝牙 → HID 直连」，选择「让 Windows 查找平板」，点「直连」并允许被发现。在 Windows 蓝牙设置中选对应的经典蓝牙设备并确认配对。Windows 列表里显示 `Bluetooth LE Device` 已连接时，请看平板的小墨板是否报告连接成功，并实际移动笔测试。HID 直连的可用性取决于设备，也可能暂停平板上的其他蓝牙外设。遇到问题时可切换兼容蓝牙或局域网。白板专用的侧键和双指手势请使用小墨板桌面接收器。

### 在线连接码

两端需要能访问并信任同一个自建 HTTPS 配对服务。电脑开启局域网接收并选好 IPv4，再进入「设置 → 在线连接码」，填「配对服务」地址，点「保存地址 → 生成连接码」。平板从「局域网 → 使用在线连接码」填相同地址和十位码。连接码五分钟内有效，只能领取一次。配对服务交换加密连接资料，笔数据随后直连电脑，因此平板仍需能访问电脑所在网络。 [在线配对服务部署说明](https://github.com/Tetro02/XiaoMoBan/blob/v0.6.7/relay/README.md)

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到电脑 | 先确认电脑端局域网接收已开启。自动发现失败时，用正确的 IPv4 和六位码或二维码。仍然连不上时，检查是否在隔离的访客网络，以及 Windows 防火墙是否允许小墨板在当前可信网络接收连接。 |
| 日志显示 10048，或局域网显示备用端口 | 10048 表示监听地址已被占用。0.6.7 优先用 `57211`，冲突时试 `57214`，两者均占用时由 Windows 分配空闲端口。实际端口显示在「局域网」页。两端均升级到 0.6.7，再扫新二维码或重新配对。若防火墙规则只允许旧端口，请检查新端口在当前可信网络是否可用。 |
| 六位码不可用 | 如果只是六位码服务的 `57213` 冲突，局域网笔输入仍可通过二维码配对。已配对设备也可尝试直接连接。 |
| USB 扫描不到平板 | 检查数据线、USB 调试、平板解锁及授权提示。确认桌面端能找到 `adb.exe`，然后点「刷新设备」。只出现「未授权」时，在平板确认调试提示。多台设备同时连接时，手动选择正确的平板。 |
| USB 提示端口被占用 | Windows 本机的 USB 监听端口 `57212` 冲突时，新版会自动换电脑端口。如果日志明确说「平板上的 USB 转发端口 57212 已被占用」，先正常退出使用该转发的程序，再重新连接平板。 |
| 笔能移动但写不出压感 | 选择「绝对笔」，确认电脑端已勾选「将笔事件输出到 Windows」，用「打开试笔」检查轻重。如果试笔有压感，检查目标应用是否启用了 Windows Ink。 |
| 按侧键后弹出三星浮窗或笔迹中断 | 先从「笔设置 → 侧键诊断」重现。若确认三星浮窗在抢占侧键，可在平板系统的「S Pen → 浮窗指令」中关闭对应动作。该设置也会影响其他应用。 |

需要排查监听端口时，可在 Windows PowerShell 中运行下面的命令。输出中的 `OwningProcess` 可在任务管理器「详细信息」的 PID 列查到。 [微软端口查询文档](https://learn.microsoft.com/en-us/powershell/module/nettcpip/get-nettcpconnection) · [10048 错误码说明](https://learn.microsoft.com/en-us/windows/win32/winsock/windows-sockets-error-codes-2)

```powershell
Get-NetTCPConnection -State Listen -LocalPort 57211,57212,57213,57214 -ErrorAction SilentlyContinue |
    Select-Object LocalAddress, LocalPort, OwningProcess
```

报告问题时，附上两端版本、Windows 与平板型号、连接方式、重现步骤，以及「设置 → 连接与日志」中相关几行。请遮住二维码、配对码和密钥。 [提交问题](https://github.com/Tetro02/XiaoMoBan/issues)
